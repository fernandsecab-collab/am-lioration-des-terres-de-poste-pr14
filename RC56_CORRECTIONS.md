# RC56 — Rapport identique à l’aperçu logiciel

- Suppression du générateur Word indépendant qui reconstruisait le rapport avec une autre mise en page.
- Le bouton **Word client** capture maintenant chaque page A4 réellement affichée dans l’onglet **Rapport premium**.
- Chaque page est intégrée à l’identique dans le DOCX : mêmes blocs, mêmes espacements, mêmes couleurs, mêmes logos, mêmes schémas, mêmes cartes et mêmes photos.
- Le rendu exporté ne peut plus diverger de l’aperçu du logiciel, car il utilise directement les pages affichées comme source unique.
- Conservation de l’autorisation d’édition en mode bureau même lorsque le dossier est incomplet ; les obligations terrain restent inchangées.
